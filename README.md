# Automation-Project-etch-AI (자동 동기화)

팀 저장소 [code5312/Automation-Project-etch-AI](https://github.com/code5312/Automation-Project-etch-AI)를
매시간 자동으로 따라가는 사본입니다.

- 프로젝트 코드는 `main` 브랜치에 있습니다. 이 `sync-bot` 브랜치는 동기화 설정만 담고 있습니다.
- 동기화 때마다 팀 저장소 내용으로 덮어쓰므로, 이 저장소의 `main` 등에 직접 수정하면 사라집니다.
- 개인 수정용 사본은 별도 저장소 soomin-01/Automation-Project-etch-AI를 사용합니다.
